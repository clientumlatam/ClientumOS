The module is a thin React shell composed of four files. `src/main.tsx` is the single entry point that creates the React 18 root via `createRoot` and renders `<App />` inside `<StrictMode>`. `src/App.tsx` is the top-level component holding global UI state (`activeTab`, `currency`, `region`, `isCommandPaletteOpen`, `currentUser`) and dispatching it to child components: `Sidebar`, `Header`, `Breadcrumbs`, `CommandPalette`, and one of ~30 feature tab components rendered conditionally by `activeTab` string comparison. A special `public_website` tab bypasses the dashboard layout entirely and renders `PublicWebsite`. Authentication is handled imperatively through `fetch('/api/auth/me')` on mount and `fetch('/api/auth/logout')` on logout, with cross-component sync via a custom `auth-changed` DOM event. `src/types.ts` centralizes shared TypeScript types, most notably the `ActiveTab` union literal that enumerates every supported tab key and serves as the single source of truth for tab routing. `src/index.css` imports Tailwind CSS via `@import "tailwindcss"`, making Tailwind utilities available globally.
