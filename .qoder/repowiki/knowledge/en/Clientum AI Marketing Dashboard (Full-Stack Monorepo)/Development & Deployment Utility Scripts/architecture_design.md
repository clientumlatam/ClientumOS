Flat collection of standalone CLI scripts with no shared library — each file is an independent entry point invoked directly via `node <script>` or `python3 <script>`. The scripts fall into four functional groups: (1) Environment setup — `generate-env.mjs` auto-populates `.env` from a `DEFAULT_VARS` map with optional factory functions; `setup-env.js` provides an interactive guided wizard using `readline`; both parse `.env`/`.env.example` files with a simple key=value parser. (2) Secret management — `pull-secrets.mjs` fetches decrypted env vars from the Vercel project API (`/v9/projects/{id}/env?decrypt=true`) and writes `.env.local`, while `sync-secrets.mjs` bidirectionally syncs secrets from Replit env to Vercel env vars and GitHub Actions secrets (with libsodium/tweetsodium encryption and a `gh` CLI fallback). (3) Health diagnostics — `doctor.mjs` runs async probes against PostgreSQL (Neon), Gemini, Groq, OpenRouter, Apify, Google Maps, Hunter.io, SMTP, Santi SDR, Vercel, and GitHub, reporting latency and status icons. (4) Data processing — `generate_catalog.py` reads `src/data/servicios-catalogo.json`, enriches it with derived fields (category, software, tipo, tags, SEO keyword, meta description) via regex-based classification rules, and writes back JSON plus a WooCommerce-ready CSV. All scripts read `.env.local` as a fallback source for process.env before checking system environment variables.
