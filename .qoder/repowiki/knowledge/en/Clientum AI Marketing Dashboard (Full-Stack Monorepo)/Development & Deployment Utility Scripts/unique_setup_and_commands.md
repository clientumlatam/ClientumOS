Each script is run directly with Node/Python: `node scripts/doctor.mjs`, `node scripts/generate-env.mjs`, `node scripts/setup-check.mjs`, `node scripts/pull-secrets.mjs`, `node scripts/sync-secrets.mjs --dry-run`, `node scripts/setup-env.js`, `python3 scripts/generate_catalog.py`. Secrets are sourced from Replit Secrets (in Replit), `.env.local` (local dev, gitignored), or system `process.env`. `sync-secrets.mjs` supports a `--dry-run` flag to preview changes without writing.
