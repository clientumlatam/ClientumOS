The `.refact/` directory is a flat collection of YAML/JSON configuration files consumed by the Refact tooling ecosystem. The root `project_information.yaml` declares schema version, global defaults (max chars/items), and per-section toggles with size limits for system info, environment instructions, detected environments, git info, project tree, instruction files, project configs, and memories — acting as the single source of truth for what context gets surfaced to agents. Each subdirectory (`background_agents`, `buddy`, `code_lens`, `knowledge`, `modes`, `subagents`, `tasks`, `toolbox_commands`, `trajectories`) holds one or more declarative config files that define capabilities in a uniform YAML/JSON shape; there is no shared library or build step inside this module — it is purely data-driven configuration consumed at runtime by the Refact orchestrator. The `buddy/runtime_queue.jsonl` file shows an append-only event log used by the buddy subsystem, indicating some directories also hold transient runtime state alongside static config.
