TypeScript (ES2022, bundler module resolution, path alias `@/*` → root), Vite 6 + React 19 + Tailwind v4 for the SPA, Express 4 + `express-session` + `connect-pg-simple` for the backend, PostgreSQL via `pg` pool, Google Generative AI (`@google/genai`) with multi-model fallback, Firebase SDK for client-side config/rules, bcryptjs for password hashing, nodemailer for SMTP, and esbuild for server-side bundling. Development runs via `tsx server.ts` with Vite HMR.
