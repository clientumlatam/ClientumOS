`npm run setup:env` (run automatically before `dev` via `predev`) bootstraps environment variables; `npm run dev` starts the Express server with `tsx`; `npm run build` produces a Vite SPA plus an esbuild-bundled `dist/server.cjs`; `npm start` runs the production server; `npm run clean` removes build artifacts. Vercel deploys via `index.ts` exporting the Express app as a serverless handler.
