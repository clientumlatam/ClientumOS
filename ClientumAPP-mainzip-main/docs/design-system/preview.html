Ordenar por contexto, no por inventario

Las secciones agrupan lo que la persona hace. Los módulos secundarios se mantienen disponibles sin competir con el trabajo diario.

Principios de uso

Reglas que deben sobrevivir a cualquier pantalla.

Usar el azul con intención

Acciones primarias, navegación activa y enlaces. No saturar cada panel con el color de marca.

Hacer visible el siguiente paso

Los estados vacíos, alertas y resultados deben orientar una acción concreta.

Diseñar para lectura rápida

Separar título, contexto, dato y etiqueta. Reservar mono para cantidades, códigos y métricas.

Accesibilidad desde el sistema

Foco visible, nombres accesibles, contraste suficiente y ningún estado comunicado sólo por color.
