# Oportunidades y Pipeline de Ventas B2B (ClientumOS)

## Descripción General
El módulo de Oportunidades representa el corazón comercial de ClientumOS. Permite gestionar todo el embudo de ventas B2B con vistas Kanban, de tabla y métricas en tiempo real.

### 2. Etapas del Pipeline Comercial
1. **Nuevo Lead (Calificación inicial)**
   - Prospectos ingresados por WhatsApp, Formularios o Importación CSV.
   - Acciones: Asignar responsable, calificar con MEDDIC.
2. **Contacto / Reunión Agendada**
   - Videollamada inicial de descubrimiento de necesidades.
   - Documentación de dolores y requerimientos técnicos.
3. **Propuesta Comercial Enviada**
   - Presentación de presupuesto, alcance de los 16 módulos y licencias.
4. **Negociación Activa**
   - Discusión de términos contractuales, SLA y métodos de pago (MercadoPago / Transferencia).
5. **Cerrado / Ganado**
   - Emisión automática de Factura A con CAE (AFIP) y alta en Portal del Cliente.
6. **Cerrado / Perdido**
   - Registro de motivos de pérdida para análisis de objeciones.
